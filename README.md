# Smart Package Locker Management System

A locker system where delivery agents store packages and customers collect them with a
pickup code. It's built with Java 21 and Spring Boot, with a small Vue UI.

> Work in progress. This README is completed in the final step.

## Requirements

- JDK 21 or newer. Nothing else: the Maven Wrapper downloads Maven.

## Build and test

```bash
./mvnw verify
```

On Windows, use `mvnw.cmd verify`.

## Run

```bash
./mvnw spring-boot:run
```
